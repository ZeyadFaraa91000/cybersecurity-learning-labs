# Linux Basic Commands

## Objective
Learn basic Linux commands and understand how to inspect files and directories.

## Commands Practiced

### 1. Show the current directory
```bash
pwd
```
Displays the path of the current working directory.

### 2. List files and directories
```bash
ls
```
Lists files and directories in the current location.

### 3. Show detailed file information
```bash
ls -l
```
Displays permissions, ownership, size, and modification time.

### 4. Change directory
```bash
cd /tmp
```
Changes the current directory to `/tmp`.

### 5. Display the current username
```bash
whoami
```
Prints the username of the current user.

## Practice Notes
Run each command in your own Linux environment and record what you observe.

## Safety
Commands in this document are intended for basic system navigation and inspection.
